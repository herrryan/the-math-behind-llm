## 1. 老师给你的系统核心认知：LLM 执行的物理第一性原理

在翻开具体的代码前，老师希望你先在脑海中刻下一条铁律：

> **“在数学世界里，大模型是优雅的概率投影；但在物理世界里，大模型本质上是一个受限于‘带宽’和‘容量’的流水线物流系统。”**

你写下的每一行深度学习代码，背后都有三个真实的物理裁判在对你进行无情的打分：
1. **主厨的手速有多快？（Tensor Core 峰值算力）：** 芯片一秒钟最多能敲击多少次乘加计算？
2. **冷库送菜有多宽？（显存 HBM 带宽）：** 从显存把数据搬到芯片运算核心上，通道到底有多宽？
3. **分店调货有多慢？（跨卡通信互联带宽）：** 当单张显卡装不下、必须两张甚至上万张显卡协同作业时，网线和交换机是否会堵死？

```
                            [物理现实的三重裁判]

                 [主厨切菜: 算力 COMPUTE] 
                 单卡 1000~2000 TFLOPS
                          ▲
                         / \
                        /   \
                       /     \
                      /       \
                     ▼         ▼
      [冷库搬运: 显存 MEMORY] ◄──► [跨店调配: 通信 INTERCONNECT]
      HBM 带宽: 2~3.35 TB/s        NVLink/网络: 400~900 GB/s
```

任何算法的优化，本质上就是在**算力**、**显存**和**通信**这三者之间做极其精妙的算账平衡。
