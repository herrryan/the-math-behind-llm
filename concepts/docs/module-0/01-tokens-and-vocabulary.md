# 概念 01 - 乐高文字积木：词元切分（Tokenization）与词典暗号表

---

## 老师引言：电脑看不懂唐诗宋词

同学，当你在 ChatGPT 的输入框里敲下一句“明月几时有”，你脑海中浮现的是汉字的音形义。
但计算机的本质只是一堆电子开关，它只认得电流的高低电平，连字母都不认识，更别提方块字了。

那么，大模型在正式开始动脑筋之前，第一步必须做什么？
答案是：**必须把人类的自然文字，整整齐齐地切割成能够编号入库的标准化零件——词元（Token）。**

---

## 生活实体模型：乐高工厂的分类料盒

想象你走进了一家巨大的乐高玩具拼装车间：
1. **极端方案 A（按整句存）**：如果每个可能出现的句子都专门开一个模具，那工厂需要上千亿个料盒，世界上句子无穷无尽，厂房直接挤爆；
2. **极端方案 B（按最小笔画存）**：如果把所有字都拆成横竖撇捺，模具倒是极少（只要几个基本笔画），但拼一首诗需要成百上千个零件，工人累得手抽筋，拼装速度慢如蜗牛；
3. **最聪明的方案（乐高自适应积木）**：
   - 极其高频出现的词，直接做成一个完整零件（比如“的”、“人工智能”、“the”）；
   - 比较罕见的生僻词，拆成两三个常用部首或音节积木（比如把“ChatGPT”拆成“Chat”和“G”、“PT”）。

在大模型中，这套拆装乐高积木的规则就叫做**词元切分算法（如 BPE 算法）**，而车间里所有合法零件的清册，就叫做**词典（Vocabulary）**。

```
原始句子: "我非常喜欢看人工智能相关书籍"
      │
      ▼ (乐高切分刀: 切分成标准零件)
零件列表: ["我", "非常", "喜欢", "看", "人工智能", "相关", "书籍"]
      │
      ▼ (查字典对暗号: 每个零件对应一个唯一数字 ID)
数字暗号: [2891, 78102, 1045, 892, 45109, 321, 6781]
```

---

## 它在大模型里到底怎么工作？

现在的尖端大模型（如 LLaMA-3、GPT-4）通常维护一本包含 **100,000 到 128,000 个零件**的固定字典：

1. **输入阶段（文字变数字）**：
   当一句话输入进来，切词器（Tokenizer）以最贪婪的方式在词典里找最长匹配的积木，将文字转换成一串整数 ID。
2. **输出阶段（数字变回文字）**：
   当大模型在脑海深处计算出下一个词的 ID 是 `45109` 时，解码器直接在字典第 45109 行查出对应的字样是 <samp>“人工智能”</samp>，呈现在你的屏幕上。

## 如果拿掉它，世界会怎样？

你可能会问：“老师，为什么大模型有时候算数不好？比如问它 `9.11` 和 `9.9` 哪个大，它有时候会答错？”

秘密往往就藏在切词器里！
因为在切词器的眼里，数字不一定被切成单个数字，而是可能把 `9.11` 切成 `[9, .11]`，把 `9.9` 切成 `[9, .9]`。大模型看到的是零件标签，而不是真正的十进制数轴！
同样，大模型做诗数不对字数、写藏头诗常常翻车，也是因为汉字被拼装积木打包了，它看到的是一个个“暗号块”，而不是汉字的方块字形！

## 老师划重点

!!! tip "核心心法"
    **Token 就是大模型世界里的标准乐高积木。切词器是大模型与人类世界翻译的第一道关卡，它决定了模型感知文字粒度与计算效率的上限。**
