# 大模型底层核心概念（零数学通识课）

> 彻底剥离高深数学公式，用纯粹直觉、生活实体隐喻与清晰机械模型，带你游历现代大语言模型（LLM）的全栈心智宇宙。

## 老师发刊词：如果完全不用公式，大模型到底是如何思考的？

同学，你好！欢迎来到这门专为你打造的大模型底层核心概念课。

市面上的大语言模型教程往往呈现两极分化：
1. **一类过度通俗，沦为走马观花**：告诉你“大模型就像个黑盒、是个概率复读机”，却解释不清为什么它能写代码、做推理、甚至产生令人惊叹的智能涌现；
2. **一类过度硬核，被数学符号筑起高墙**：铺天盖地的矩阵求导、微积分链式法则、非欧几里得几何度量与希腊字母，直接把没有深厚高数功底的探索者拒之门外。

本课程立志打破这个两难困境。**我们的宗旨是：不写一行繁复的数学求导公式，不罗列令人头晕的矩阵符号，却绝不牺牲底层机制的严谨性与深刻度！**

我们将大模型内部每一个核心组件的精髓，还原为三岁孩子也能看懂的物理现实：
- 为什么**词嵌入（Embedding）**本质上就是一张城市经纬度地图？
- 为什么**矩阵变换**就像一台变换视角的魔法照相机？
- 为什么**自注意力机制（Self-Attention）**不是什么神秘魔法，而是一场全员各取所需的圆桌图书借阅会？
- 为什么**残差连接（Residual Connection）**是高层大厦里的应急直通滑梯？
- 为什么**温度（Temperature）**是调控大模型是谨小慎微还是天马行空的恒温器？

无论你是刚入局的人工智能产品经理、求知若渴的软件工程师，还是对大模型心智充满好奇的终身学习者，只要你带着好奇心与常识思维，老师就能带你推开大模型的每一扇内部重门。
