# 概念 24 - 虚拟显存货架：PagedAttention 如何消除碎片、像操作系统一样管显存

---

## 老师引言：为什么明明显存显示还剩一半，系统却说装不下了？

在计算机工业界，常常发生一种让人捶胸顿足的怪事：
系统管理员打开监控面板，明明看到昂贵的 GPU 显存还剩下整整 40 GB 的空闲空间，然而当一个新的用户发来一条只有几十个字的消息时，系统却当场报错崩溃，拒绝提供服务。

这就像你去停车场停车，明明放眼望去到处都有空位，保安却挥着旗子把你轰走：“没车位了！”
这种荒谬的显存浪费被称为**内存碎片化（Memory Fragmentation）**。
而彻底终结这一顽疾、让大模型并发吞吐暴涨数倍的超级英雄，就是如今大名鼎鼎的 **PagedAttention（分页注意力）**。

---

## 生活实体模型：大学图书馆占座与智能寄存柜

### 1. 传统显存分配：霸道的大学图书馆占座
在 PagedAttention 诞生之前，推理引擎管理 KV Cache 便利贴的方式极其古板：
当一个用户连接进来时，系统根本不知道他最终会聊几句。
系统心想：“万一他要聊满 2048 个字呢？”
于是，系统二话不说，**一口气在显存里给这位用户霸占了一整条必须完全连续的 2048 个空槽位**！
- 结果这个用户只问了句“你好”，得到了“你好呀”三个字，就心满意足地离开了；
- 剩下的 2040 多个连续空槽位，在对话没有彻底结束前，任何其他人都绝对不能用！
更要命的是，显存里东空一块、西空一块，全是散碎的小缝隙。哪怕空闲容量总和很大，却连一个完整的连续大长条都拼不出来！**高达 60% 到 80% 的珍贵显存就这样被白白挥霍了。**

### 2. PagedAttention 革命：火车站的自动储物柜
现代操作系统的内存管理早在几十年前就解决了这个问题，这就是传奇的**虚拟内存分页机制**。
加州大学伯克利分校的研究团队灵光一闪：*为什么不把操作系统的分页思想借给大模型？*

他们发明了 **PagedAttention**：
- 不再提前霸占整条连续显存，而是把显存切成一个个固定大小的标准储物盒（例如每个盒子固定装 16 个词元的 KV 数据，称为一个“Page/块”）；
- 用户的对话说满 16 个字，系统就从散落的货架上随便抓一个空盒子给他用；
- 再说满 16 个字，再随便抓一个空盒子。这些盒子在物理显存里可以天南海北、互不相连，只需要一张轻巧的**目录指引表（Page Table）**把它们串起来！

```
┌────────────────────────────────────────────────────────────────────────┐
│                      PAGEDATTENTION 虚拟货架映射示意                   │
├────────────────────────────────────────────────────────────────────────┤
│ 用户逻辑感知: [ 词元 0~15 ] ──► [ 词元 16~31 ] ──► [ 词元 32~47 ]      │
│                     │                   │                   │          │
│ 映射指引目录表:    指向块 #3           指向块 #8           指向块 #1          │
│                     │                   │                   │          │
│ 物理显存散布:    [物理块 #1]         [物理块 #3]         [物理块 #8]         │
│                 (放第32~47词)       (放第0~15词)        (放第16~31词)        │
│ ──► 散落在天涯海角的碎盒子里，被目录表串联成一条丝滑的长文本！         │
└────────────────────────────────────────────────────────────────────────┘
```

## 它在大模型里到底怎么工作？

PagedAttention 不仅把显存浪费率从 80% 狠狠砸到了 **1% 以下**，还附赠了一个近乎魔法般的超级特异功能——**写时复制（Copy-on-Write）与前缀共享**！

想象一下，如果有 10 位用户同时在向大模型咨询同一篇 10,000 字的法律合同：
- 在过去，系统必须把这 10,000 字在显存里原样复制整整 10 份，显存瞬间告急；
- 在 PagedAttention 里，这 10 位用户的目录表全部指向**同一批物理盒子**！10 个人零成本共享同一份长篇记忆；
- 只有当某位用户自己产生独一无二的新回复时，系统才单独为他分配新盒子。

这就是当今全球几乎所有主流大模型服务框架（如 vLLM）底层的力量源泉。

## 如果拿掉它，世界会怎样？

如果没有 PagedAttention：
- 我们现在租用 GPU 云服务器的费用至少要翻三到五倍；
- 当很多用户同时提问时，服务器能承载的并发人数会缩水到原先的五分之一；
- 所谓的多人共享长上下文（如代码库检索、长文档客服问答）将变成企业根本无法承受的昂贵奢侈品。
